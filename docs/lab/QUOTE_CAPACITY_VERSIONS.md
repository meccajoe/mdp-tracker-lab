# Choosing which quote version drives Capacity

Every independent quote initially represents its own project. Similar names are never grouped automatically.

## Existing duplicate estimates
1. On Quotes, open the three-dot menu for an older or alternate quote.
2. Choose **Group / change project**, then choose another quote for the same project.
3. Save grouping. The moved quote stops contributing demand; the destination group's current selection stays selected.
4. On the version you want to forecast, click **Use for Capacity**. Only one version per group is selected.

These controls preserve quote contents, prices, Draft/Final state and revision history. Grouping requires edit permission for every affected version. Quotes list and quote header indicate the selected version. Changes reach Capacity immediately in the same browser, or on its normal refresh on another device.

## New versions
Clone offers **New version of this project** (default) and **Separate project**. A new version stays out of Capacity until selected, even if dates and forecast were copied. A separate project starts independently selected. Marking a version Closed Won selects it automatically; other group versions stop contributing demand. Draft/Final does not choose the capacity version.

## Forecast and schedule
Only the selected version contributes shop, trade, CAD and field hours to full-hours and probability-weighted forecasts. Team Schedule also requires the selected quote to be Active. Version selection does not copy project dates, task actuals, approvals or schedules between versions; review those on the chosen quote.

## Corrections and archives
Use Group / change project → Separate project to undo an incorrect association. It becomes an independently selected project again. Moving the selected quote away from a group, or archiving it, does not silently promote an older estimate: explicitly choose Use for Capacity on a remaining version if needed. All archived quotes remain recoverable.
